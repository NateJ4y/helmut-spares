# Helmut Spares

Custom storefront foundation for Helmut Spares, built with Next.js, TypeScript and Tailwind CSS for deployment on Vercel.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current build stage

- [x] Initial Next.js App Router scaffold
- [x] Brand foundation based on the supplied Stitch direction
- [x] Responsive homepage structure
- [ ] Product catalogue and vehicle-aware search
- [ ] Product detail pages
- [ ] Hybrid cart and assisted enquiry flows
- [ ] Admin/CMS and inventory management
- [ ] Checkout and payment integration
- [ ] Content, stock, fitment and policy verification with Helmut

## Important

This is a frontend foundation, not a live commerce system yet. Product availability, fitment, pricing, delivery terms, warranties, payment processing and response-time promises must be verified with Helmut before launch.
